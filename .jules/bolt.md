## 2026-04-18 - Pre-computing HTTPX URLs in Tight Loops
**Learning:** In Python HTTPX clients, parsing string URLs to `httpx.URL` objects inside the request loop adds measurable overhead. When benchmarking HTTP client code for performance optimizations, testing string manipulations (like pre-computing URLs vs dynamic f-strings) against zero-latency network endpoints (like ASGI transports) can reveal underlying CPU efficiency gains. Pre-computing static URLs into `httpx.URL` objects during initialization avoids per-request string parsing and significantly improves performance in tight execution loops.
**Action:** When a Python application frequently calls static endpoints in tight loops, construct and cache `httpx.URL` objects at class initialization and pass them directly to the client's `.get()` or `.post()` methods instead of relying on string parsing for every request.
